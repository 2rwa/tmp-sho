この実装で物理的に計算しているもの

各管ごとに、(1) 簧を片持ち梁の1自由度モードとして積分、(2) 簧周囲の開口面積から Bernoulli 流量を計算、(3) 簧自身のポンピング流量を加算、(4) 円筒管を往復遅延 + 開口端反射として帰還させています。簧開口面積は2003年論文の F(x)=W√(x²+b²)+2L√((0.4|x|)²+b²) を採用。流路慣性項は同論文の線形解析で通常範囲では無視できるとされたため v0.1 では省略しています。

吹奏 / 吸奏の非対称（v0.2実験項）

通常モードの既定値は対称（倍率1.0）のままです。論文検証モードでは、簧裏面のわずかな削りによる幾何学非対称を drawEscapeScale、流れの上流/下流配置差を drawContractionRatio として一次近似します。canonical-ramp retune run 36301182111 で選び、canonical regression run 36301453344 で昇格した modern/reference は smoothing=0.62, reflection=0.875, Q=14, αm=0.35, escape=2.40, C-ratio=1.40 です。「一」管で blow 372 Pa / draw 89 Pa、ringdown は数値ゼロ近傍まで減衰します。実測比較値 370/90 Pa は近似値なので狭い許容幅で回帰します。非対称量は実測形状そのものを同定した値ではありません。

既知の未実装部分

最重要なのは共通の匏（かしら）内部の音響結合です。2002年測定では匏側圧力に高周波振動があり、形状・容積が音色へ大きく影響する可能性が示されています。一方2003年モデルは匏内圧 p(t) を外部入力として、流量から匏へ戻る結合を意図的に無視しています。したがって、この版は「論文モデルの再構成 + 15管化」であり、複数管間の共通風箱結合まで再現した最終版ではありません。

数値安定性

非線形流量と管入口圧の代数ループは各サンプルで Newton 反復。AudioWorklet が使えない file:// 環境では ScriptProcessor にフォールバックします。最終段にDCカット、12 kHzローパス、ソフトクリップを置き、スピーカー保護用に出力を抑えています。
