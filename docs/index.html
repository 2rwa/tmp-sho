笙の物理音源モデル
公開検証ノート

日本の笙（shō）の自由簧・管共鳴・吹奏/吸奏非対称・匏（かしら）の共通圧力結合を、再現可能な数値実験として検証しています。公開対象は生成した実験データ、再現条件、文献情報、生成音です。会話ログ、内部メモ、個人情報は掲載しません。
